# ART-Music
Music Player App - është një aplikacion inovativ për menaxhimin dhe shijimin e përmbajtjes muzikore, i cili ndryshe nga platformat e tjera, sjellë një ndërfaqe ultra-lehtësi përdorimi, shpejtësi maksimale dhe një fokus unik tek personalizimi i përvojës së përdoruesit **pa reklama të padëshiruara.**
